# DMPS Family Connect

Crea una aplicación web moderna, pública, intuitiva y completamente responsive llamada provisionalmente “DMPS Family Info”.

OBJETIVO DEL PROYECTO

La aplicación servirá como una biblioteca pública de información para las familias de Des Moines Public Schools (DMPS). Las familias podrán encontrar información, instrucciones, recursos, anuncios, imágenes y videos sin registrarse ni iniciar sesión.

Solamente los administradores o editores autorizados deberán iniciar sesión para crear, editar, actualizar, organizar, publicar o eliminar contenido.

La experiencia para las familias debe ser extremadamente sencilla, rápida y accesible, especialmente para personas que:

No dominan bien la tecnología.

Utilizan principalmente teléfonos móviles.

Hablan diferentes idiomas.

Necesitan instrucciones claras y fáciles de seguir.

Tienen conexiones de internet lentas.

No obligues a las familias a crear una cuenta, iniciar sesión, proporcionar correo electrónico ni entregar información personal.

ESTILO VISUAL

Crea una apariencia:

Moderna, profesional y acogedora.

Inspirada en portales educativos actuales.

Con fondo principalmente blanco.

Con azul profundo como color principal.

Con colores secundarios suaves.

Con tipografía grande y fácil de leer.

Con suficiente espacio entre elementos.

Sin pantallas sobrecargadas.

Sin estilo excesivamente corporativo o serio.

Con animaciones pequeñas, fluidas y discretas.

Debe funcionar perfectamente en teléfono, tableta, Chromebook y computadora.

Utiliza componentes reutilizables y mantén un diseño uniforme en toda la aplicación.

IDENTIDAD Y LOGOTIPO

Reserva un espacio visible para el logotipo oficial proporcionado por el propietario del proyecto.

No inventes, deformes ni recrees el logotipo oficial de DMPS. Utiliza inicialmente un marcador de posición que pueda reemplazarse fácilmente desde el panel administrativo.

Si este proyecto no ha sido aprobado oficialmente por DMPS, incluye en el pie de página un aviso configurable que diga:

“Este recurso informativo no representa un sitio web oficial de Des Moines Public Schools, salvo que DMPS indique lo contrario.”

El administrador podrá activar, desactivar o modificar este aviso.

SEGURIDAD

Configura Row Level Security correctamente.

Reglas esenciales:

Cualquier visitante puede leer únicamente contenido publicado y visible.

Los visitantes no pueden crear, editar ni eliminar artículos.

Los borradores solo pueden ser consultados por usuarios autorizados.

Los usuarios administrativos solamente pueden ejecutar acciones permitidas por su rol.

Solo el administrador principal puede administrar permisos críticos.

Validar formularios y archivos antes de guardarlos.

Limitar tipos y tamaños de archivos.

No exponer claves privadas en el frontend.

No almacenar contraseñas manualmente.

Utilizar el sistema seguro de autenticación del backend.

Registrar acciones administrativas importantes.

No almacenar datos personales de las familias mediante la búsqueda o navegación pública.
